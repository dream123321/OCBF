# DCBF Update - 2026-07-24

## 中文

- 修正 `per_configuration` 筛选：低覆盖率的后 20% 规则现在按构型独立执行，阈值可通过 `mean_descriptor_low_coverage_threshold` 设置，默认值为 `90.0`。
- 修正下一轮 MD 种子：只有尚未达到全部已启用覆盖率阈值的构型才会写入 `stru.pkl`。
- 数据集 builder 新增 `dataset_mode: augment_existing`，支持将已有数据集与随机位移、声子位移及 MLIP-MD 生成的新结构合并；只标注新结构，并优先保留已有数据及其标签。
- 示例 JSON/JSONC 已同步新增参数。
- LAMMPS 丢原子警告现在报告错误发生前最后一个成功输出的 MD `step`，不再显示 `original/current` 原子数。
- `main_loop_npt` 和 `main_loop_nvt` 支持使用空子列表跳过单个系综，并校验二者是否等长配对；coverage query 会分别采用 NPT 和 NVT 的最后一个非空温度，并将轨迹合并。
- 修复 Coverage-PCA 在 input 与 query 数据元素不一致时出现的空数据错误；缺失元素会被自动跳过，不参与 PCA 和覆盖率计算，并记录到 `coverage_remark.txt`。
- 新增 `npt_max_cell_volume_filter_factor`：默认以种子晶胞体积的 `1.5` 倍为上限，过滤异常膨胀的 NPT 候选；设置为 `null` 可关闭过滤，数值低于 `1.1` 时自动回退到 `1.5`。该过滤不影响 NVT、覆盖率、预算、plateau 和 `stru.pkl`；若本轮候选全部被过滤，则跳过 DFT 并继续下一 generation，不写入 `__end__`。

## English

- Fixed `per_configuration` selection: the final-20% rule for low-coverage configurations is now applied independently to each configuration. The threshold can be set with `mean_descriptor_low_coverage_threshold` and defaults to `90.0`.
- Fixed the MD seeds used in the next generation: only configurations that have not reached all enabled coverage thresholds are written to `stru.pkl`.
- Added `dataset_mode: augment_existing` to the dataset builder. Existing datasets can now be combined with new structures generated by random displacement, phonon displacement, and MLIP-MD. Only new structures are labeled, while existing data and labels are preserved with priority.
- Updated the example JSON/JSONC files with the new parameters.
- LAMMPS lost-atoms warnings now report the last successfully recorded MD `step` before the error instead of the `original/current` atom counts.
- `main_loop_npt` and `main_loop_nvt` now support empty inner lists to skip an individual ensemble, with validation that the two schedules have matching lengths. The coverage query uses the last non-empty temperature from NPT and NVT separately and merges their trajectories.
- Fixed the Coverage-PCA empty-data error that occurred when the input and query datasets contained different elements. Missing elements are skipped automatically, excluded from PCA and coverage calculations, and recorded in `coverage_remark.txt`.
- Added `npt_max_cell_volume_filter_factor`: by default, NPT candidates with cell volumes exceeding `1.5` times the seed-cell volume are filtered out. Set it to `null` to disable the filter; values below `1.1` automatically fall back to `1.5`. This filter does not affect NVT, coverage calculations, budgets, plateau logic, or `stru.pkl`. If all candidates in a generation are filtered out, DFT is skipped and the workflow continues to the next generation without writing `__end__`.
